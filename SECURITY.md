# Security Policy

## Reporting a vulnerability

Please do not report security vulnerabilities through public GitHub issues.

Until a dedicated reporting channel is published, contact the project owner privately through the website contact form or LinkedIn profile. Include a clear description, steps to reproduce, affected area, and any suggested mitigation.

Reports will be acknowledged as soon as practical. Please allow time for investigation and remediation before disclosing details publicly.

## Scope

Security reports are especially welcome for authentication, authorisation, form validation, rate limiting, data exposure, dependencies, and deployment configuration.

Do not access, modify, or exfiltrate personal data while testing. Use the minimum proof necessary to demonstrate an issue.
