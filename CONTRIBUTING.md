# Contributing

Thank you for helping improve the Ewuji John platform.

## Before you contribute

- Search existing issues before opening a new one.
- Use an issue template for bugs, content corrections, training ideas, and accessibility concerns.
- Keep pull requests focused on one coherent change.
- Do not include credentials, personal data, private training records, or production configuration in issues, commits, or pull requests.

## Pull requests

1. Create a branch from `main`.
2. Make and test the change locally.
3. Update relevant documentation or content.
4. Open a pull request that explains the purpose, testing completed, and any accessibility impact.
5. Address review feedback before merging.

## Content contributions

Technical content should be accurate, testable, and written in clear language. Include source links where appropriate, descriptive alt text for images, and a meaningful next step for readers.

## Code of conduct

By contributing, you agree to follow the [Code of Conduct](CODE_OF_CONDUCT.md).
